## F. Pratiques volontairement écartées (délai de 5 jours)

| Écarté | Pourquoi | Quand le reconsidérer |
|---|---|---|
| Microservices, un service par agent | Complexité de déploiement sans bénéfice | Jamais pour cette échéance |
| Event sourcing complet | Rejeu d'effets de bord, coût | Si le rejeu devient exigence forte |
| Celery / Redis / RabbitMQ / arq | Un service de plus dans l'image | Multi-instances |
| PostgreSQL d'emblée | Pas de besoin multi-écrivains | Plusieurs instances d'API |
| LangGraph / AG2 / CrewAI / OpenAI Agents SDK | Orchestration pilotée par le LLM ou rejeu de nœuds, contraire à l'audit déterministe | Si la reprise devient complexe |
| ChromaDB comme **source de vérité** | Non process-safe pour écrivains concurrents [V, cookbook officiel] ; **retenu comme index vectoriel** (SQLite reste la source de vérité) — voir [07](07-knowledge-and-rag.md) §7.3 | — |
| Arbre de Merkle (RFC 9162) | Preuve d'inclusion inutile ici | Preuves à un tiers |
| React Server Components / Next.js, Redux | Inutile pour une SPA servie par FastAPI | — |
| WCAG AAA, tests de charge lourds, auth fédérée | Hors délai | Après la finale |
